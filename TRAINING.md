# Go7Flicks training

This is the short index. The baseline is [PRODUCT-BIBLE.md](PRODUCT-BIBLE.md). The plan at `~/.cursor/plans/go7_shorts_local_editor_c31fa3ff.plan.md` points here and at the bible. When a control is added or refused, update the bible first, then this index.

Go7Flicks is its own Windows and Mac app. Workhorse stays the desk. A template starts a flick. The canvas can then be cut by hand. A pasted link is downloaded when the person presses Get. The file lands in the channel.

Status words: **in the app**, **next**, **refused**. The full list, the screen-by-screen path, the performance numbers, and the Workhorse call paths are in the bible.

## Index

- **Home.** Baseline is one greeting and two cards: Video Ranking and Split. Auto Clipping, Text Story, the transcriber, and image gen stay later and off the first click. See bible sections 2 and 4. Frames: `docs/concepts/home.png`, `docs/concepts/ranking.png`.
- **Drew and Wes.** Both on Windows. Installer steps are in `WINDOWS.md`. This Mac has not built it.
- **Video ranking.** In the app: title, highlight words, stroke, font, caption size, caption color, warmth, Paste captions, Show captions, 5–7 slots, countdown, listed, skip around, shuffle. On the ranking desk, Play ranking plays every filled cut in the current order, and This clip plays the selected video from start to end. The phone crops toward the person and shows the rank and the caption. Open timeline opens that same ranking on the full timeline. Polish and local auto-clip candidates are next.
- **Split, commentary, canvas, templates.** In the app. The canvas inspector has the same font, caption size, caption color, warmth, Paste captions, and Show captions. A saved template keeps that style and still drops the media. Script-to-scenes, chat templates, kinetic captions, a sound catalog, and the heavier timeline tools are next.
- **Dual video.** In the app, from the Split Screen card. Half by default, face or gameplay on top, both clips heard, seam still moves. Frame: `docs/concepts/dual-video.png`.
- **Voice, cut export, styled export.** In the app. Styled export uses hardware acceleration when possible, bitrate 8M, and `crf` null.
- **Connections.** Claude, Codex, Grok, Cursor, ElevenLabs, MiniMax, Other. No auto-router and no usage rings. Grok’s key row is `https://api.x.ai/v1`, model `grok-4.7`. Cursor uses the agent already on this computer and does not keep a second key. A Gemini API key can go on Other. This app does not call the Gemini app subscription or Antigravity.
- **Subject finder.** In the app. Find clips is on the ranking desk, at the top of the inspector. The person names a specific subject and presses Find clips. The main process looks for clips of that subject, not a generic viral video, and downloads three clips under 90 seconds with the same downloader as Get, skipping a longer video, a compilation, and a robot, news, interview, or building-collapse title. The subject picks the kind of clip, a fall or a jump counts, and the result is a short set the person can rank and cut. A short result whose title does not name the subject waits when other short clips do. Parkour brings parkour clips. Gardening brings gardening. Baking brings baking. A military subject brings military clips. The clips are staged locally and land in empty ranking slots. A slot that already has a clip stays put. Find clips trims to the loudest moment on this computer, keeps the crop centered, and sets the headline from the subject. Skip around plays the ranks out of numeric order. The window does not call yt-dlp or the network. The cut stays on this computer. Find clips does not call the Gemini subscription or Antigravity. Get still downloads a link the person already pasted. Finding an existing clip of that subject is a different job from drafting a new idea or generating a new picture. The app does not browse on behalf of a vague “make me something viral” request. The subject is the point.
- **Which clip.** In the app, on the ranking desk under the headline and on the canvas under Text and style. It still ranks a set that is already on the flick. It asks the connected chat row which clip already on this flick is the strongest hook, and for a headline plus a short title per clip. Apply headline and Apply title write those words. The assistant does not reorder or delete clips. What trend asks what kind of video this set already is. It does not browse the web or download a video. ElevenLabs speaks a line. It does not search for footage. ElevenLabs and MiniMax stay voice. No connected chat row means the control says so and does not invent a ranking.
- **Get.** A pasted link downloads into the channel. If that folder is on a network drive, preview and export use the working copy on this computer.
- **Library dates.** The library shows when a video was made and when a flick was clipped. A channel lists each flick by name and clipped date. The shelf shows a readable clip name, with Made as the quiet date, and a raw filename is not a caption.
- **Working copies.** In the app, on Library. A network or UNC file is copied there before preview, cut, and styled export. A file already on a local disk is not copied again. The folder defaults to this app’s user data and can be changed. An empty or invalid folder falls back to that default. Clean unused, next to Change, removes working copies no timeline still uses, unfinished export pieces, and a numbered extra of a flick’s export. An export with its own name stays. It leaves source clips on a timeline alone, and it does not change a network drive.
- **Refused.** The Remotion Timeline component, and reading Workhorse’s secret store. A model that declines a line is that model’s reply.
- **Packaging.** Mac dmg script is in the repo. Windows NSIS still has to be built on a Windows PC. The $10 month waits until both boys can make a channel.

## Where a few rules live in code

`playbackOrder` in `src/shared/canvas.ts` is the ranking rule. Countdown sorts by rank, high to low. Listed keeps the rail. Skip around plays the ranks out of numeric order. Shuffle follows the id list from the last Shuffle press and does not rewrite `rank`. The ranking desk shows that play position on each slot, then Open timeline writes the clips in that order.

Create and save timing for an empty channel lives in `test/create-save.perf.test.ts`. The latest run is recorded in the bible.
