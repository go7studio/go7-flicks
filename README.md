# Go7 Flicks

The Windows setup is on the [latest release](https://github.com/go7studio/go7-flicks/releases/latest).

The page to share is [go7studio.com/products/go7-flicks](https://go7studio.com/products/go7-flicks). Anyone with that link can open it. No Go7 account and no GitHub login.

The installer is not code-signed. Windows will say the publisher is unknown. Take the file only from this release, then choose More info, then Run anyway.

Open Go7 Flicks. On Home, start Video Ranking or Dual video. Add clips that are already on the PC, then Open timeline and pick a folder.
